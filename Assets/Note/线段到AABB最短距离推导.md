# 线段到局部 AABB 的最短距离推导

本文解释 `OrientedBoundingBox.SegmentToAabbDistanceSquared` 的数学原理。胶囊体在 OBB 局部空间中表示为一条中心线段和半径；先求中心线段到局部 AABB 的最短距离，再与胶囊半径比较。

## 1. 问题定义

局部 AABB 以原点为中心，半尺寸为 `extents = (ex, ey, ez)`，所以三个轴的范围分别为：

```text
x: [-ex, ex]
y: [-ey, ey]
z: [-ez, ez]
```

设线段起点为 `S = start`，终点为 `end`，方向向量为：

```text
D = end - start
```

线段上的点用参数 `t` 表示：

```text
P(t) = S + t * D, 其中 0 <= t <= 1
```

求线段到 AABB 的最短距离，等价于在 `0 <= t <= 1` 范围内，求点 `P(t)` 到 AABB 的距离最小值。

## 2. 点到 AABB 的距离

在坐标轴 `i` 上，点坐标为：

```text
p_i(t) = s_i + t * d_i
```

盒子在该轴的范围是 `[-e_i, e_i]`。该坐标超出盒子的距离为：

```text
separation_i(t) = max(abs(p_i(t)) - e_i, 0)
```

因此，点到盒子的距离平方为：

```text
F(t) = sum(separation_i(t)^2), i in {x, y, z}
```

若坐标在盒子范围内，该轴贡献为 0；若坐标在盒子外，该轴贡献为点到最近盒面的距离平方。使用距离平方可以避免开平方，最终直接与 `radius * radius` 比较。

## 3. 为什么按穿过盒面的参数分段

`abs` 和 `max` 使得整个 `F(t)` 不是同一个多项式。但某一轴只有在线段穿过该轴的盒面时，才会从盒内变成盒外，或从盒外变成盒内。

对于第 `i` 个轴，两个盒面分别是 `-e_i` 和 `e_i`。令线段坐标等于盒面坐标，可得交点参数：

```text
tMin = (-e_i - s_i) / d_i
tMax = ( e_i - s_i) / d_i
```

仅当 `0 < t < 1` 时，这个交点位于线段内部，需要作为分段边界。若 `d_i == 0`，线段在该轴上不移动，不会穿过该轴的盒面，因此跳过。

将 `0`、`1` 和三个轴上的有效交点参数排序后，线段被分成若干区间。每个区间内部，各轴相对盒子的状态不变，因此该区间的距离平方是一个普通二次函数。

每轴最多有两个盒面交点，总计最多六个内部交点；加上线段端点，参数数组最多需要八个位置。

## 4. 每个分段中的距离函数

对当前分段取中点，判断每个轴在整个分段内是位于盒内、盒子下方还是盒子上方。由于分段已经在所有穿面参数处切开，中点的状态代表该轴在整个分段内的状态。

### 4.1 坐标在盒内

若 `-e_i <= p_i(t) <= e_i`，该轴距离为 0，不参与二次函数。

### 4.2 坐标在盒子下方

若 `p_i(t) < -e_i`，到下侧盒面的有符号差为：

```text
p_i(t) - (-e_i) = s_i + t * d_i + e_i
                    = d_i * t + (s_i + e_i)
```

距离是上述值的绝对值，但平方后符号不影响结果：

```text
separation_i(t)^2 = (d_i * t + (s_i + e_i))^2
```

因此代码把该轴的 `offset` 设为 `s_i + e_i`。

### 4.3 坐标在盒子上方

若 `p_i(t) > e_i`，到上侧盒面的差为：

```text
p_i(t) - e_i = d_i * t + (s_i - e_i)
```

所以该轴的距离平方为：

```text
separation_i(t)^2 = (d_i * t + (s_i - e_i))^2
```

代码把该轴的 `offset` 设为 `s_i - e_i`。

## 5. 二次函数的极小值

将当前分段中所有处于盒外的轴的距离平方相加：

```text
F(t) = sum((d_i * t + offset_i)^2)
```

展开并合并同类项：

```text
F(t) = Q * t^2 + 2 * L * t + C

Q = sum(d_i^2)
L = sum(d_i * offset_i)
C = sum(offset_i^2)
```

`C` 不影响极小值所在的位置，因此代码不需要累加它。对 `F(t)` 求导：

```text
F'(t) = 2 * Q * t + 2 * L
```

令导数为 0：

```text
tClosest = -L / Q
```

代码中的 `quadratic` 对应 `Q`，`linear` 对应 `L`。由于无约束的 `tClosest` 可能不在当前分段内，必须将它限制到当前分段的 `[intervalStart, intervalEnd]`：

```text
tClosest = clamp(-linear / quadratic, intervalStart, intervalEnd)
```

若 `Q == 0`，说明所有参与距离的轴在线段方向上的分量均为 0，该分段内距离不会因 `t` 改变；取分段起点即可。

## 6. 重新计算距离并取得全局最小值

根据求出的参数重新计算线段上的最近候选点：

```text
closestPoint = start + direction * tClosest
```

然后使用点到 AABB 的直接公式重新计算它的距离平方：

```text
separation_i = max(abs(closestPoint_i) - e_i, 0)
distanceSquared = sum(separation_i^2)
```

对每个分段都执行上述计算，取最小的 `distanceSquared`。由于每个分段都精确求出了该段的最小值，所有分段中的最小值就是整条线段到 AABB 的最短距离平方。

## 7. 用于胶囊体判定

胶囊体可表示为中心线段沿半径 `r` 膨胀形成的形状。线段到盒子的距离为 `d` 时：

```text
胶囊与盒子相交或接触 <=> d <= r
```

平方后避免开平方：

```text
distanceSquared <= radius * radius
```

线段穿过或进入盒子时，线段到盒子的距离为 0，因此任何非负半径的胶囊都会相交。线段靠近盒子的边或角时，算法使用三个轴向距离平方之和，保留了欧氏距离，不会像“每个轴都扩张半径后做 Slab 检查”那样在角落产生额外误报。

## 8. 边界与退化情况

- **零长度线段**：`start == end` 时，算法退化为点到 AABB 的距离计算。
- **线段平行于某个盒面**：对应轴的 `direction` 为 0，不会产生该轴的穿面参数；该轴的内外状态在整条线段上不变。
- **线段与盒面相切**：分段边界可能重复。零长度分段仍能被计算，不改变最终最小值。
- **线段位于盒内**：所有轴的距离贡献为 0，得到最短距离平方 0。
- **胶囊总高度小于直径**：中心线段应退化为一点；构造中心线段时使用 `max(0, height / 2 - radius)` 作为半长。
