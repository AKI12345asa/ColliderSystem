# EPA 算法迭代流程

EPA（Expanding Polytope Algorithm，扩展多面体算法）通常接在 GJK 之后使用：GJK 确认两个凸形状相交，并给出一个包含原点的 Minkowski 差单纯形；EPA 逐步扩展这个单纯形，求出最接近原点的边界面，从而估算穿透法线和穿透深度。

本文中的点集均指 Minkowski 差空间中的点。若形状 A、B 在方向 `d` 上的支撑点分别为 `supportA(d)` 和 `supportB(-d)`，则 Minkowski 支撑点为：

```text
support(d) = supportA(d) - supportB(-d)
```

## 1. 输入条件

EPA 的起始输入必须是一个**包围原点的非退化凸多面体**，在三维情况下通常是 GJK 得到的四面体。四面体的顶点必须是 Minkowski 差空间中的支撑点，而不是直接把两个形状的顶点混在一起。

如果 GJK 只返回 `bool`，EPA 还无法启动：需要让 GJK 在相交时同时输出最终 Simplex。若 Simplex 退化、原点仅落在线段或三角形上，或者四面体未将原点包在内部，需要先由 GJK 阶段补充支撑点并确认得到有效四面体；不能直接对退化初始体运行标准 EPA。

## 2. 初始化四面体面

四面体有四个三角面。为每个面计算单位外法线 `n` 和有符号面距离 `d`：

```text
n = normalize(cross(v1 - v0, v2 - v0))
d = dot(n, v0)
```

要求法线朝向多面体外侧，使原点在多面体内部时 `d >= 0`。若 `d < 0`，翻转法线或交换三角面顶点顺序，使法线和距离符号一致。此时离原点最近的面，是 `d` 最小的有效面。

实现时可将面及其距离作为一个条目存入最小堆。距离应在面创建时计算并缓存，后续堆比较只比较缓存值。不要用无符号距离掩盖法线方向错误；外法线和正的面距离是 EPA 几何意义的一部分。

## 3. 迭代扩展

每轮从优先队列中取出离原点最近的有效面 `F`：

1. 取面外法线 `n`，沿该方向查询两个形状的支撑点，得到 Minkowski 点 `p = support(n)`。
2. 计算新支撑点到该面的距离 `dP = dot(n, p)`。面距离记为 `dF`。
3. 若 `dP - dF <= tolerance`，该面已足够接近 Minkowski 差边界，迭代收敛。
4. 若未收敛，使用新点 `p` 扩展当前多面体：
   - 找出从外侧可见的所有面。对面上的顶点 `v`，若 `dot(face.normal, p - v) > visibilityTolerance`，该面可见。
   - 删除所有可见面，并收集这些面与非可见区域相邻的边，形成边界边（horizon）。
   - 消除内部边：若边界集合中同时存在方向相反的边 `(a,b)` 和 `(b,a)`，两者是内部边，应成对移除。
   - 对每条剩余有向边 `(a,b)`，创建新面 `(a,b,p)`，调整顶点顺序使面法线向外，并计算、缓存新面的距离后加入候选集合/最小堆。
5. 进入下一轮，继续取当前最近的有效面。

伪代码：

```text
faces = 四面体的四个外向面
priorityQueue = faces，按面距离由小到大

for iteration in 0 .. maxIterations:
    face = 取出最近的有效面
    p = support(face.normal)
    projectedDistance = dot(face.normal, p)

    if projectedDistance - face.distance <= tolerance:
        return face.normal, face.distance

    visibleFaces = 找出从 p 可见的面
    horizon = visibleFaces 与非可见区域的边界边
    删除 visibleFaces

    for edge in horizon:
        newFace = 由 edge 和 p 创建的外向面
        faces 加入 newFace
        priorityQueue 加入 newFace

返回未收敛状态
```

实际实现中，若堆条目对应的面已因扩展而删除，取堆顶时必须识别并跳过这些过期条目；也可以使用可删除优先队列，或使用“面集合 + 每轮线性扫描最小距离”的结构。只用一个最小堆而没有管理可见面、horizon 和已失效面，无法完成 EPA 的多面体扩展。

## 4. 收敛结果

收敛时：

- **穿透法线**：最近面的外法线 `n`，方向约定需在整个碰撞响应系统中保持一致。
- **穿透深度**：最近面的距离 `dF`。在多面体正确包围原点、法线为单位外法线时，该距离应为非负值。
- **接触点**：仅有 Minkowski 点不足以还原两个物体各自的接触点。创建每个支撑点时应同时保存 `supportA(n)` 和 `supportB(-n)`。收敛面上的最近点可用三角形重心坐标对面的三个支撑点分别插值，得到 A、B 两侧接触点；二者可用于计算接触位置或取中点作为近似接触点。

## 5. 容差与退出条件

需要设置最大迭代次数和几何容差，避免浮点误差、重复支撑点或退化面造成无限循环。至少处理以下情况并返回明确状态，而不是伪装成正常收敛：

- 初始四面体无效或未包围原点。
- 最近面队列为空，或剩余面均已失效。
- 新支撑点与已有顶点重复，扩展不再产生进展。
- 产生零面积/近零面积面或无法构成闭合 horizon。
- 预分配的顶点、面或堆容量不足。
- 达到最大迭代次数但仍未满足收敛条件。

固定容量缓冲区适合避免 Job 内托管分配，但容量不足时必须让调用方知道失败；同时，`length1 * length2` 通常不是 EPA 多面体最大面数的可靠上界，容量应依据实际扩展上限设计，或使用有界迭代次数并按最坏新增面数预算。

## 6. 与当前项目代码的对应关系

- `GJKTool.GJK` 当前主要返回相交布尔值；EPA 需要 GJK 额外输出有效的 Minkowski 四面体 Simplex。
- `GJKTool.Support` 当前返回 Minkowski 差点。若需要接触点，应扩展支撑查询结果，同时保存 A、B 两侧的原始支撑点。
- `ColliderTriangle.GetNormal` 可得到面法线，但 EPA 初始化/扩展时还需保证法线朝外且面距离符号正确。按顶点绕序建立法线后，应使用有符号 `dot(n, v0)` 校正方向。
- `MinHeap` 可用于按面距离选最近候选面，但还需配合活动面集合、可见面移除、horizon 边消除和过期堆项检查。
- 当前 `ColliderTriangle` 描述的是三角形表面。标准 EPA 用于两个有体积的凸形状；对 BVT 筛出的单个 Mesh 三角形对直接执行 EPA，三角形退化为零厚度表面，通常不能得到可靠的刚体穿透深度。

## 7. EPA 与碰撞响应的边界

EPA 输出法线和穿透深度，不会自行改变刚体运动。后续的物理响应仍需结合刚体质量/逆质量、线速度、角速度、质心、惯性张量、恢复系数和摩擦系数，计算冲量并做位置修正。多物体、多接触点场景通常还需要顺序冲量等迭代求解。
