# MVT（MTV）最小平移向量原理与碰撞响应

MVT 常被用来指 **Minimum Translation Vector**，更常见的缩写是 **MTV**，中文称为最小平移向量。它描述两个相交形状沿某一方向分离所需的最小位移。本文使用 MTV 作为术语；项目中的 `intersectSegment` / `ColliderCouple.IntersectSegment` 可承载该向量，但必须为其规定并始终遵守相同的方向约定。

## 1. MTV 表示什么

设两个形状为 A 和 B。若它们相交，MTV 的长度表示沿所选分离方向将形状移出相交状态所需的距离，方向则表示这一位移的方向。

```text
MTV = 分离方向 * 穿透深度
穿透深度 = length(MTV)
```

MTV 不是接触点，也不是速度或冲量：

- **接触点**描述碰撞发生在物体表面上的位置。
- **碰撞法线**是单位方向，通常可由 MTV 归一化得到，但它的正负方向取决于系统约定。
- **穿透深度**是非负标量。
- **MTV**同时携带方向和深度。
- **冲量**改变速度；MTV 用于位置修正，不能直接当作冲量。

相切时穿透深度为零。离开相交状态通常还需添加很小的安全偏移，以抵消浮点误差。

## 2. 方向约定必须明确

对同一对形状，下面两种向量都能表达相同的分离量，只是方向相反：

```text
将 A 移开 B： MTV_A
将 B 移开 A： MTV_B = -MTV_A
```

一组 API 或结果类型必须选择一种约定，不能有的碰撞对返回 A 的修正方向，有的返回 B 的修正方向。项目中 `ColliderCouple` 会按 Collider ID 排序，因此若结果向量的方向与顺序有关，应以排序后的 `ColliderAId`、`ColliderBId` 定义正负方向，并在构造碰撞对前按 ID 顺序翻转向量。

当前项目使用 `ColliderCouple.IntersectSegment` 保存检测结果。建议将它明确约定为：

> `IntersectSegment` 是从 `ColliderA` 指向 `ColliderB` 的分离轴向量；A 的位置修正沿其反方向，B 的位置修正沿其正方向。

在该约定下，若只移动 A，则 `deltaA = -IntersectSegment`；若只移动 B，则 `deltaB = IntersectSegment`。若项目决定改用“直接施加到 A 上的位移”作为存储含义，则所有窄相检测与消费代码都必须相应统一，不能只改其中一侧。

## 3. Minkowski 差与最小平移向量

两个形状 A、B 的 Minkowski 差定义为：

```text
A - B = { a - b | a 属于 A, b 属于 B }
```

两个凸形状相交，当且仅当它们的 Minkowski 差包含原点。分离两个形状，等价于将 Minkowski 差移到不再包含原点的位置。原点到 Minkowski 差边界的最近距离给出最小穿透深度；对应边界的法线给出分离方向。

这也是 GJK 与 EPA 的关系：

- **GJK** 判断 Minkowski 差是否包含原点，并逐步逼近或构建包围原点的单纯形。
- **EPA** 从 GJK 的有效单纯形开始扩展多面体，寻找离原点最近的边界面。
- 最近边界面的单位法线和原点到该面的距离，可近似组成穿透方向与深度。

EPA 依赖有效、非退化且包围原点的初始多面体。若初始单纯形无效、扩展遇到退化几何、容量不足或迭代未收敛，就不能把失败结果误当作有效 MTV。

## 4. SAT 如何得到分离轴与重叠量

分离轴定理（SAT）适用于凸多边形/多面体：若存在某条轴，使两个形状投影区间不重叠，则两形状不相交；若所有候选轴的投影都重叠，则相交。

设某候选轴为单位向量 `n`，两个形状在该轴上的投影区间为：

```text
A: [Amin, Amax]
B: [Bmin, Bmax]
```

若 `Amax < Bmin` 或 `Bmax < Amin`，该轴是分离轴。若投影重叠，则沿该轴的正、负方向退出重叠所需距离分别为：

```text
向正方向分离： Amax - Bmin
向负方向分离： Bmax - Amin
```

选择较小的有效分离量作为该轴上的候选穿透深度。对所有必要候选轴进行比较，取最小候选值对应的轴，才能得到 SAT 意义下的最小平移方向。

候选轴必须符合形状组合：例如 OBB-OBB 使用双方三条面法线及边方向叉积；AABB-三角形使用盒轴、三角形法线及盒轴与三角形边的叉积。叉积产生的近零轴是退化候选，应跳过或安全处理。

**注意：** 只计算其中一个投影区间的宽度、或只取 `max - min`，不一定等于两区间的穿透深度。若要把 SAT 结果当作 MTV，需要比较两个区间的端点，计算两个可能退出方向的位移，并选择最小的有效值；同时根据区间中心关系确定向量符号。

## 5. 从 MTV 做位置修正

假设 `m` 是长度为 `depth` 的 MTV，单位分离法线为 `n`：

```text
depth = length(m)
n = m / depth
```

当 `depth` 近似为零时，不应直接归一化；应跳过位置修正，或使用一个稳定且有限的接触法线处理后续响应。

为避免小幅数值误差造成持续抖动，通常采用容差 `slop`，并只修正穿透量的一部分：

```text
correctionDepth = max(depth - slop, 0) * percent
```

其中 `percent` 在 `0..1` 之间。若 MTV 约定为 A 指向 B，则：

```text
correction = n * correctionDepth
deltaA = -correction * invMassA / (invMassA + invMassB)
deltaB =  correction * invMassB / (invMassA + invMassB)
```

`invMass` 是逆质量。静态物体令 `invMass = 0`，动态物体承担全部或按逆质量比例分摊修正。如果两者逆质量之和为零，则双方都不移动。Trigger 通常只产生事件，不做位置修正。

若一帧中一个物体参与多个碰撞对，不能简单地由多个并行工作项同时写同一个 Transform。应先将多个碰撞约束的修正汇总/迭代求解，再由每个 Transform 对应的唯一工作项应用最终位移，避免并发写竞争。

## 6. 位置修正与冲量响应不是同一件事

位置修正消除几何穿透，但不会自动处理碰撞后的速度。冲量响应还需要相对速度、碰撞法线、质量、恢复系数；含旋转时还需质心与惯性张量。

简化的无旋转法向冲量可使用：

```text
relativeVelocity = velocityB - velocityA
velocityAlongNormal = dot(relativeVelocity, n)
```

若 `velocityAlongNormal >= 0`，物体正在分离，通常不施加法向碰撞冲量；否则再根据逆质量和恢复系数计算冲量。法线 `n` 的正负必须与 A/B 约定一致。摩擦冲量则沿接触切向计算。

实践中应分开处理：

1. **位置修正**：用穿透深度/MTV 消除重叠。
2. **速度响应**：用法线冲量处理反弹或停止相对接近。
3. **摩擦响应**：按切向相对速度和摩擦系数限制切向冲量。

## 7. 坐标空间和方向一致性

参与同一次 GJK/EPA 运算的支撑点、单纯形和形状参数必须处于同一坐标空间。EPA 返回的法线/MTV也处于该计算空间；若在局部空间求解，需将方向变换到世界空间，并注意非均匀缩放下向量变换与法线变换并不相同。当前项目的 MeshTree 路径将三角形和 EPA 点集转换到世界空间，因此 EPA 结果是世界空间向量。

SAT 若先将几何变换到 OBB 局部空间，得到的轴向量也必须旋转回世界空间。对于纯旋转，乘以 OBB 旋转即可；有缩放时应明确变换矩阵与向量语义。

对碰撞对按 ID 排序时，还应同步调整 MTV 的符号。排序后的碰撞记录、向量方向、后续质量分摊中的 A/B 身份必须始终匹配。

## 8. 当前项目中的适用边界

- **解析几何对**（如球-球、球-胶囊、胶囊-胶囊）可由最近点与半径差计算穿透向量；最近点重合时方向不唯一，需要选择稳定的备用方向，不能归一化零向量。
- **凸形状对**可用 SAT 或 GJK+EPA 计算相交与近似 MTV；必须处理退化轴、零深度、无效输入和容量/迭代失败。
- **凹 Mesh**不能直接当作一个凸形状使用。把整张 Mesh 顶点作为支撑点集合，实际表示其凸包；这会填满凹陷区域，所得 EPA 向量只是凸包近似。
- **BVT 三角形筛选**能找到局部候选接触，但一个零厚度三角形不是普通具有体积的凸实体。不能因为三角形 GJK 命中，就认为对“整张凹 Mesh”执行标准 EPA 得到的向量一定是该局部接触的精确穿透量。
- **多接触场景**可能存在多个候选分离方向，单个 MTV 不等于完整刚体约束解。实际稳定性通常需要多个接触点、迭代约束求解和速度响应。
- **返回值必须区分失败和零向量**。若检测报告相交但 EPA 未收敛，应使用明确的失败状态或回退策略；零向量既可能表示刚好相切，也可能表示没有成功算出 MTV。

## 9. 实现与检查清单

- 明确向量表示“从谁指向谁”或“直接施加给谁”的约定。
- SAT 从两个投影区间的端点计算候选穿透量，而不只比较区间宽度。
- 在所有碰撞对中统一坐标空间、ID 排序和向量符号。
- 处理最近点重合、轴叉积退化、零深度和非有限数值。
- 检查 GJK/EPA 的成功状态；不要把算法失败解释成有效相交向量。
- 将位置修正、法向冲量和摩擦冲量分开实现。
- 对多个碰撞对的修正进行安全汇总，避免并发写同一 Transform。
- 用单元测试覆盖相切、深度为零、中心/最近点重合、静态-动态、双方动态、ID 顺序反转和旋转盒体等情况。
